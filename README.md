# ConexaoZoo

Aplicação em Node.js para gerenciamento de dados de um zoológico, com integração a banco de dados MySQL.

## Tecnologias

- Node.js
- Express
- Sequelize
- MySQL
- Handlebars

## Como executar

```bash
npm install
npm start
```

Configure a conexão com o banco de dados antes de executar a aplicação.

## Banco de dados

O arquivo `zooSql.sql` contém a estrutura SQL utilizada pelo projeto.
